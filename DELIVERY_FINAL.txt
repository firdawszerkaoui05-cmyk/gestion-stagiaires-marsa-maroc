```bash
Content-Type: application/json

{
  "stagiaire": {
    "nom": "Ahmed",
    "prenom": "Hassan",
    "email": "hassan@example.com",
    "telephone": "+212612345678",
    "etablissement": "FST Settat",
    "profil": "Bac+3 Informatique",
    "type_stage": "Obligatoire",
    "date_debut": "2026-06-01",
    "date_fin": "2026-08-31"
  }
}

# Response: 200 JSON avec aperçu et affectation IA générée
```


## 💻 Frontend - Intégration simple

```javascript
import FicheAccueilDownloader from './components/FicheAccueilDownloader';

// Dans Dashboard.js
<FicheAccueilDownloader 
  stagiaire={{
    nom: "Ahmed",
    prenom: "Hassan",
    email: "hassan@example.com",
    telephone: "+212612345678",
    etablissement: "FST Settat",
    profil: "Bac+3 Informatique",
    type_stage: "Obligatoire",
    date_debut: "2026-06-01",
    date_fin: "2026-08-31"

/>
```
